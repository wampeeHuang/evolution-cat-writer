0

素材理解 + HKIR 质检

主 session · SKILL.md §第一步
吃透用户提供的素材（brief / 链接 / PDF / 语音转文字 / 散乱想法）。跑 HKIR 质检：Happy（有趣？有悬念？）· Knowledge（有信息量？）· Inspiration（有启发性？**I 是硬门槛 — 不通过直接杀**）· Resonance（戳中情绪？）。S 级四项兼备，及格线 I 必过 + H/K/R 至少一项。信息不够主动问用户。
→ 选题判定（继续 / 沟通调整 / 放弃）
门禁 · Step 0
I（启发性）必过 → 继续；I 不通过 → 🔴 杀稿；I 过但 H/K/R 全不占 → 杀稿
没有启发性的选题不进入下一步。素材不够 → 主动问用户补充。
杀

杀稿门禁 · 写前硬拦截

主 session · SKILL.md §杀稿门禁
HKIR 通过后、动笔前，跑三道杀稿问。①认知税：读者要理解几个陌生概念？≥3 → 🔴 杀。②洞察值：最终洞察是"操原来可以这样"还是"嗯我知道"？后者 → 🔴 杀。③分享货币：读者转给朋友能靠转发完成自我表达吗？转不出手 → 🔴 杀。0 红灯过，1 红灯过但补强，2+ 红灯杀稿。杀稿后素材保留，选题回库标记"碎片待拼"。
→ 过/杀 · 杀稿写 .abandoned
杀稿门禁 · 写前拦截
0-1 红灯 → 过（1 红灯写作时补强）；2+ 红灯 → 🔴 杀
认知税过重 / 无洞察 / 转不出手 → 杀稿不留。部分亮点撑不起整篇 → 标记"碎片待拼"。
1

AI 角色边界确认

主 session · SKILL.md §第二步
明确此次写作中 AI 负责什么、人负责什么。AI 擅长：找证据佐证、找类比比喻、按确定角度扩写、补充背景知识、梳理逻辑结构。人必须做：第一手观察和真实经历、核心创意角度、情绪的真实表达（体感记忆而非知识性描述）。
→ 协作边界清晰
2

写作执行

主 session · SKILL.md §第三步
三步串联：①判断文章原型（调查实验 / 产品体验 / 现象解读 / 工具分享 / 方法论分享）→ ②应用对应原型的写法重心 → ③按结构模板写作（开头→背景→核心内容→收尾→署名）。全程应用风格框架中的⚙️通用规则和👤个人偏好。
→ draft-v1.md
门禁 · Step 2
原型判定正确 + 结构模板完整 + 风格框架规则已应用
结构不完整 → 退回到对应板块补写。原型选错 → 重新判断。
3

四层质检

主 session · SKILL.md §质检体系
L1 硬性规则检查（禁用词/标点/结构套话/空泛工具名 — 扫描零命中）→ L2 风格一致性（开头/节奏/语言/结尾 — 全部通过）→ L3 内容质量（观点支撑/知识输出/类型专项/扣主线 — 全部通过）→ L4 活人感终审（温度/独特性/姿态/心流 — 像真人写的）。
→ 质检报告 + draft-v2.md
退回门禁 · Step 3
L1 零命中 → 通过；L2-L4 任一 FAIL → 返工对应段落重写
L4 活人感 FAIL → 把"AI 味重"的段落找出来，用更口语、更私人、更不完美的���式重写。

可选 · 复盘生长

→ flesh/ 信号更新

5 种文章原型
原型核心句式写法重心
调查实验型"我替你去做了"过程叙事 + 层层递进的发现
产品体验型"跟我一起玩"场景演示 + 真实感受 + 产品对比
现象解读型"你注意到了吗？"观察→好奇→研究→升维
工具分享型"我发现了好东西"个人故事铺垫→工具展示→效果
方法论分享型"压箱底的东西"可执行行动 + 坦诚学习曲线
第一篇文章「截图落盘中转站」= 工具分享型原型。痛点→追根因→找到工具→效果→反思。
风格框架 · 规则分类
⚙️ 通用规则 👤 进化猫个人
维度⚙️ 通用（不随人变）👤 进化猫（从文章提取）
语言讲人话、真诚不骗、拥抱不完美直接不废话、三段式情绪推进、品牌比喻、自嘲式身份
节奏长短句交替、一句成段、波动推进板块分隔用 -- 、不写小标题
开头具体事件切入，禁止宏大叙事痛点直击+动作描述、叙事启动
知识输出聊着聊着顺手掏出来"我查了一下，答案很离谱"式好奇心
结尾自然收束，不啰嗦反思段→金句→固定署名✨
标点服务于口语节奏冒号可用 · →流程衔接 · ~语气延长
幽默自然流露，不刻意搞笑品牌反差 · 直白吐槽 · 自嘲
👤 列的内容来自「截图落盘中转站」提取。待用户确认后有更多文章可进一步生长。
7 项通用写作技法
技法一句话说明
人物画像法从数据点出发 → 3-5 句内让一个人物立体
层层剥开现象→表面解释→更深追问→核心洞察
反向论证先满足期待再打破，"我也曾经这样想"
疑问句刹车用疑问句让读者停一秒，准备接收新信息
逐一展示法升番逻辑 — 最弱放前面，最炸留最后
回环呼应契诃夫之枪 — 前面埋的钩子结尾收
谦逊铺垫给出建议前先降低读者防御心
L1 绝对禁区 · AI 味禁用词
1 禁用："说白了"
2 禁用："本质上"
3 禁用："换句话说" / "不可否认"
4 禁用："首先...其次...最后"
5 禁用："值得注意的是" / "不难发现"
6 禁用："让我们来看看..."
7 禁用："在当今AI时代" / "随着技术发展"
8 禁用：空泛工具名 → 必须具体名称
9 禁用：假设性例子 "比如有一次..."
10 禁用：连续 bullet point ≥3 个
