## 设计哲学

### 归档不是为了怀旧，是为了不制造混乱
旧版本保留为独立仓库而不是直接删除——引用旧 URL 的用户不会遇到 404。但内容明确标注"已归档"和"路由目标"，不让人在两个版本之间困惑。

### 路由比复制好
旧的 writer 不复制 evolution-cat-article 的逻辑，只做路由转发。一份逻辑一个家——复制的逻辑必定漂移。

## 诚实边界

- **不独立工作。** 被触发时转发到 evolution-cat-article
- **保留仅用于向后兼容。** 新项目直接使用 evolution-cat-article
